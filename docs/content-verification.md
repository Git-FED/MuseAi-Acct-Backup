# Content Verification Rules

The public site must distinguish:

- **User-reported:** an account holder's description that has not been independently verified.
- **Verified:** supported by provider documentation or a reproducible test with a dated source.
- **Unknown:** plausible but not established by available evidence.

Every provider instruction requires a source URL and `last_verified` date. Do not invent support contacts, export menus, recovery times, reset behavior, or incident details. The project is independent and unofficial.

Do not state that a lockout proves theft, that retries extend a lockout, that background workers remain active, or that another account restores access unless authoritative evidence supports the exact claim.
