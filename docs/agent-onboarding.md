# Agent Onboarding

Before granting access to an AI agent:

- Define the narrowest required permissions.
- Prefer short-lived, scoped tokens.
- Keep root credentials outside the agent.
- Record the owner, purpose, expiration, and rotation process in the inventory.
- Establish a manual fallback before enabling automation.
- Test export, revocation, and recovery procedures with dummy data.
- Confirm that no customer or regulated data is being sent unnecessarily.
